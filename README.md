# vibe-coding-poradnik
Sztuka Programowania na Czuja - Kod Pisany Intuicją

Interaktywny poradnik vibecodingu dla osób, które nie umieją programować:
**opisujesz słowami → AI pisze kod → widzisz efekt na żywo**.

- Strona: https://michalstankiewicz4-cell.github.io/vibe-coding-poradnik/ (po włączeniu GitHub Pages)
- Plan i pomysły: [PLAN.md](PLAN.md)

## Uruchomienie

Czysty HTML/CSS/JS, bez instalowania czegokolwiek. Wystarczy otworzyć `index.html` w przeglądarce.

## Struktura

```
index.html            strona (spis treści + router)
css/style.css         wygląd, motyw jasny/ciemny
js/app.js             silnik: strona główna, odtwarzacz lekcji „Prompt → Efekt”
js/lessons/menu.js    lekcja: Menu nawigacyjne (5 kroków)
PLAN.md               plan działów i pomysły
```
